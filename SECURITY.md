# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report it privately through GitHub: open the [Security tab](https://github.com/MendesMat/ControlService/security) of this repository and choose **Report a vulnerability**. Include the steps to reproduce and the impact you expect.

You will get an answer within 7 days. Once the problem is confirmed and fixed, the report can be made public, with credit to you if you wish.

## Supported versions

This project is in active development. Only the latest commit on `main` receives fixes.
